## 4. Starting-Skill provenance test — LOCKED

For every proposed fresh starting Skill:

1. **Did this exact representation possess/use/know it before the representation's opening play state?**  
   If yes, it may be selected into the fresh starting package.

2. **Is the capability justified only by an occurrence/reward inside the Origin/Chronicle?**  
   If yes, it is **not** a starting Skill; it requires that committed unlock.

3. **Canon supports it later, but SC deliberately moves it earlier?**  
   An explicit SC backstory/divergence justification is required. Famous future capability does not back-propagate automatically.

4. **The Skill name is character-authentic but the mechanic is filler/generic?**  
   Character association does not justify palette occupancy. Redesign/remove rather than preserve a weak slot merely for name recognition.

## 5. Identity-anchor requirement

Every fresh starting package must contain at least one **identity-anchor Skill**: a Skill whose exact mechanic visibly expresses a core capability lane of that representation.

Additional slots should express legitimate supporting lanes such as:

- Nature transformation;
- Taijutsu style;
- Bukijutsu/weapon identity;
- Genjutsu;
- Fūinjutsu;
- Kinjutsu;
- Bloodline/clan capability when Access is legitimately available;
- Summon/source capability when legitimately available;
- another exact Character-defining branch.

**Elemental is an example, not a mandatory slot.**
