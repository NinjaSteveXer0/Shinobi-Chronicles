## 2. KEEP — formal Bloodline / kekkei genkai / dōjutsu / higher-lineage capability families

The following are retained for Shinobi Chronicles:

1. **Ketsuryūgan** — Chinoike Clan dōjutsu / kekkei genkai.
2. **Jūgo Clan Kekkei Genkai / Sage Transformation lineage** — retain the inherited natural-energy/body-transformation lineage; exact SC naming and separation between inherited condition, transformation state and Skills remain to be closed.
3. **Kurama Clan Kekkei Genkai** — unnamed canon/anime Bloodline associated with exceptionally potent Genjutsu manifestation; do not invent a false official name.
4. **Ranmaru's Kekkei Genkai** — unnamed ocular/sensory Bloodline; do not invent a false official name.
5. **Iburi Clan Kekkei Genkai** — unnamed smoke-body transformation Bloodline; do not collapse it into generic `Smoke Release`.
6. **Mud Release** — retain as the canon/novel advanced nature Bloodline candidate; exact Japanese/original display name must be verified before final UI naming if localisation authority is uncertain.
7. **Typhoon Release** — retain as the canon/novel/anime advanced nature Bloodline candidate; exact Japanese/original display name must be verified before final UI naming if localisation authority is uncertain.
8. **Ryūzetsu's Kekkei Genkai** — unnamed life-restoration/life-transfer Bloodline from *Blood Prison* continuity; do not name the Bloodline after one technique without explicit Codex authority.
9. **Yanaru's Kekkei Genkai** — unnamed clone-information-link Bloodline from novel material; do not invent a false official name.
10. **Rinha Clan Kekkei Genkai** — unnamed chakra/identity-memory duplication lineage ability from licensed game continuity; retain with continuity-source provenance visible in future Codex work.
11. **Jōgan** — retain as a high-tier ocular lineage capability with fail-closed semantics where canon remains ambiguous.
12. **Senrigan** — retain as an exceptional ocular/shinjutsu-linked capability; information scope must be tightly source-authored.
13. **Kokugan** — retain as an exceptional Ōtsutsuki/Karma-linked ocular capability; ordinary hereditary acquisition must not be inferred.
14. **Rinne Sharingan** — retain as higher-order ocular lineage capability / kekkei mōra-tier state, not an ordinary common Bloodline unlock.
15. **All-Killing Ash Bones** — retain the Kaguya/Ōtsutsuki higher-order lineage expression as a future capability route; classify as an advanced lineage technique/expression rather than falsely treating it as a standalone ordinary Bloodline family.

These fifteen are retained as canon-derived **Bloodline / dōjutsu / higher-lineage capability content**, but each keeps its own correct source taxonomy.

Preserve:

**kekkei genkai != dōjutsu automatically**  
**dōjutsu != ordinary hereditary unlock automatically**  
**kekkei mōra / Ōtsutsuki capability != common Bloodline research node**  
**named technique != Bloodline family**  
**continuity-specific ability != universal manga-canon fact**

## 3. KEEP — hereditary / clan-linked capabilities that are NOT to be mislabeled as Bloodline Limits

Stephen also approves retaining the following five canon lineage/clan capability families for Shinobi Chronicles, but they must remain outside formal Bloodline Limit taxonomy unless later canon/Codex authority proves otherwise:

16. **Shion's inherited future-sight capability** — hereditary/familial foresight from movie continuity; retain as lineage capability, not automatically `kekkei genkai`.
17. **Uzumaki Chakra Chains / Adamantine Sealing Chains** — retain as an Uzumaki lineage/clan capability route; exact possession, heredity and Skill Access remain separate.
18. **Uzumaki vitality / life-force traits** — retain as lineage traits; do not turn them into a hidden direct Base PL bonus.
19. **Hydrification Technique / Hōzuki clan body-liquefaction system** — retain as a Clan Art / lineage-associated hidden technique family, not a formal Bloodline Limit.
20. **Akimichi calorie-conversion / body-expansion system** — retain as an Akimichi Clan Art / hereditary-clan development family, not a formal Bloodline Limit.

Canonical project rule:

> **A capability can be deeply hereditary, clan-defining and mechanically important without being classified as a Bloodline Limit.**

This distinction is intentional and is part of how Shinobi Chronicles should exceed systems that place Bloodlines, Cursed Seals, Hosted Entities, clan arts and advanced ocular states into one undifferentiated research bucket.

## 4. Continuity provenance must remain visible

The retained set intentionally includes material from multiple Naruto/Boruto continuities and licensed sources.

Future Codex / Combat / Progression work must preserve source provenance such as:

- manga/primary canon;
- official anime-only material;
- official novels;
- theatrical movie continuity;
- Boruto material;
- licensed game continuity.

Inclusion in Shinobi Chronicles means **SC chooses to consume the capability**, not that every source tier becomes identical canon authority.

Preserve:

`source provenance -> SC inclusion decision -> explicit SC mechanics`

not:

`SC inclusion -> source distinctions erased`.
