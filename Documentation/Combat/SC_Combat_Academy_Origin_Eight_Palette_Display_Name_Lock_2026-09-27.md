## 1. Purpose

This document closes the **player-facing Skill display names** for the eight remaining Academy Origin characters.

- Skill mechanics;
- authored Attack PL;
- guard ratios;
- control semantics;
- temporary capacity;
- transient states;
- character Stats;
- Base / Current / Effective PL;
- prepared palette order;
- progression;
- later technique access;
- Origin Story;
- Battle AI;
- rewards;
- ownership/acquisition.

The current stable Skill IDs remain the durable runtime addresses.

## 2. Research-first naming rule — reinforced

The already-locked Combat rule remains binding:

> Before naming or renaming a character-specific technique, check the character's current external canon/reference material first.

Research is used to identify:

1. established combat motifs and naming language;
2. believable current-stage technique flavor;
3. later signature techniques that must remain outside an Academy starting palette;
4. techniques or powers that would be chronologically inappropriate.

Research does **not** mean a character receives every canon technique at Academy stage.

Current-stage loadout != future technique ceiling.

Later authentic techniques remain available for proper Progression / Development / World / training / Exam / Practical / event pathways rather than being silently granted in Origin.
