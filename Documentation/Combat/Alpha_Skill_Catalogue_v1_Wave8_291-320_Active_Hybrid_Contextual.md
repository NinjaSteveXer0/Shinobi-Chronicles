## Wave-8 guardrails

1. Contextual Skills do not create their own Story/World opportunities.
2. Recognition Substitution is distinct from the passive `skill_false_identity` and remains deliberate.
3. The historical Mission-11 `arc1_m11_menma_recognition_substitution` action is not renamed/recommitted by this catalogue.
4. Identity Rebinding profile work cannot fabricate legal Rank/ownership/permissions merely because a system accepts a recognised profile.
5. Evidence/diagnostic Skills emit bounded evidence, not hidden World Truth.
6. Movement Skills require exact traversable routes and do not invent a generic movement-stat system.
7. Hosted Entity/Echo/Tailed-Beast requests preserve entity autonomy; request != consent != success.
8. `skill_kurama_voluntary_loan_request` never turns Mission-12 historical experience into standing Kurama access.
9. No contextual Skill automatically completes a Mission, opens a locked Story branch, creates loot/reward, changes Rank, grants Progression or rewrites ownership.
10. Catalogue authority is effect design only; runtime implementation/Golden remains separate.
