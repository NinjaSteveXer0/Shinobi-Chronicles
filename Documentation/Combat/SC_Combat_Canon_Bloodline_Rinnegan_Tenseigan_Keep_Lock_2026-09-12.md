# Shinobi Chronicles — Canon Bloodline Keep Lock: Rinnegan + Tenseigan

**Date:** 2026-09-12  
**Owner:** Combat / Skills / Items / Weapons  
**Status:** **BINDING PLAYER SELECTION / CANON BLOODLINE KEEP LOCK — EXACT HOLDERS, ACCESS AND SKILL PACKAGES SEPARATE**

## 1. Player decision

Stephen has explicitly selected the following canon ocular Bloodlines for inclusion in Shinobi Chronicles:

- **Rinnegan** — KEEP
- **Tenseigan** — KEEP

These join the existing Bloodline set and inherit the current Bloodline contextual capability architecture plus the low-asset / low-status production doctrine.

This document confirms inclusion only. It does not grant either Bloodline to a Character, activate it in Alpha, or author its complete technique package.

---

## 2. Shared semantic boundary

For both Bloodlines preserve:

**possession != Access != activation/state != Skill Access != Competence != Power != Mastery**

Also preserve:

- Character identity / surname != Bloodline possession automatically;
- card art / portrait != runtime Access;
- future/canon association != current representation Access;
- Bloodline Access != every technique associated with that Bloodline;
- visible eye state != automatic Base Stat or Base PL mutation;
- observer saw the eye != observer knows identity, clan, allegiance, Rank, Mastery or full capability inventory;
- high-tier Bloodline != objectively superior route in every Story/World event;
- exact Skills/effects use the existing Combat/contextual capability architecture rather than a bespoke ocular engine.

No hidden direct PL bonus is authorised by this keep decision.

---

## 3. Rinnegan — KEEP

Rinnegan is retained as a high-tier canon ocular Bloodline / dōjutsu family.

### 3.1 No universal all-powers flag

Do not implement:

`capability.rinnegan.access == true -> every Rinnegan-associated power available`

Instead an exact Rinnegan-bearing representation must separately resolve, where applicable:

- possession/provenance;
- current ocular/state form;
- executable Access;
- exact learned/available Skill or authored effect;
- source/compatibility requirements;
- competence/mastery;
- any PL/Stat projection owned by PL authority.

Different legitimate Rinnegan users/representations may therefore have different executable repertoires without contradiction.

### 3.2 Contextual use

Where exact Rinnegan capability/effect authority exists, Story/World may consume it through the existing Bloodline contextual surface using exact Skills/effects and factual contexts.

This keep lock does not itself author:

- universal chakra perception;
- universal attraction/repulsion;
- universal summoning;
- universal absorption;
- universal soul interaction;
- universal resurrection;
- space-time transport;
- any other named/high-tier Rinnegan power.

Each such effect requires explicit Combat/Skills authority and legitimate Access.

---

## 4. Tenseigan — KEEP

Tenseigan is retained as a high-tier canon ocular Bloodline / dōjutsu family.

### 4.1 Tenseigan is not `Byakugan + XP`

Do not model Tenseigan as an automatic linear upgrade that occurs because Byakugan reaches sufficient level, use count, Mastery or Progression.

Preserve:

- Byakugan possession != Tenseigan possession;
- Byakugan Access != Tenseigan Access;
- Byakugan Mastery != automatic Tenseigan evolution;
- Tenseigan acquisition/activation requires its own explicit provenance/gate authority;
- a Character may legitimately possess/use Byakugan without ever becoming Tenseigan-eligible.

### 4.2 Exact state required

Any Tenseigan contextual or Battle effect must consume an exact authorised Tenseigan state/form and exact Skill/effect authority.

No generic Tenseigan flag automatically grants a complete advanced power package.

This keep lock does not itself author:

- chakra-mode/transformation packages;
- attraction/repulsion effects;
- constructs;
- truth-seeking-orb-like effects;
- flight/mobility;
- lunar/large-scale interaction;
- Stat/PL bonuses;
- any other high-tier effect.

Those remain separate explicit mechanics decisions.
