# Shinobi Chronicles — Kinjutsu / Echo / Tailed-Beast Catalogue Boundary

**Date:** 2026-09-10  
**Owner:** Combat / Skills / Items / Weapons  
**Status:** **BINDING COMBAT CONTENT BOUNDARY — CATALOGUE EXPANSION AUTHORISED / ACCESS REMAINS SOURCE-OWNED**

## 1. Player-direction authority

Stephen has explicitly authorised the Alpha text-first Skill catalogue to expand beyond the initial 200 rows with a strong Kinjutsu focus, especially:

- Echo-related Kinjutsu;
- Menma / `arc1_menma_echo` techniques;
- Tailed-Beast / Hosted-Entity techniques;
- Kurama-linked techniques and future repeatable coordination routes.

This is a genuine caller-driven expansion and therefore does not violate the earlier content freeze point, which prohibited only count-padding and near-duplicate content.

## 2. Kinjutsu is not a universal access flag

`kinjutsu` is a Skill discipline/classification. Merely having a Kinjutsu Stat, seeing a Technique, owning a Character card, finishing a Mission, or possessing another Kinjutsu does not grant every Kinjutsu Skill.

Every catalogue row still requires its exact learned/source/relationship/capability predicate.

Preserve:

**Kinjutsu Stat != Skill ownership != Access != Competence != Power != Mastery**

No generic Kinjutsu multiplier, mana pool, cooldown system or automatic self-damage rule is created. Where a forbidden Technique has a Battle-PL cost/risk, that cost is authored on that exact Technique only.

## 3. Echo boundary

Current Arc 1 authority remains binding:

- stable Hosted Entity: `arc1_menma_echo`;
- relationship: `host_rel_menma_arc1_echo`;
- the Echo is a distinct persistent causal Entity;
- it has no independent Alpha Stat/PL ledger while hosted;
- visible manifestation does not create a second turn or deployment slot;
- reciprocal cooperation is persistent relationship development, not ownership/mastery;
- permanent `echo_menma` eligibility depends on the legitimate reciprocal-cooperation receipt/state.

Generic Echo catalogue rows therefore require an **exact compatible Echo relationship** in addition to learned Skill access. They do not become universal to every Hosted Entity merely because an Entity is labelled `Echo`.

## 4. Existing Menma Echo actions are preserved

The following already-closed Mission-12 actions remain authoritative and are **not renamed, replaced or duplicated** by the new catalogue:

- `echo_menma_reciprocal_chakra_strike` — Attack PL 34;
- `echo_menma_threaded_route_burst` — Attack PL 37, or 42 with its exact route-read setup;
- `echo_menma_route_read`;
- `echo_menma_reciprocal_guard` — 35% prevention;
- `echo_menma_adaptive_reroute` — exact compatible-state removal once/Battle.

New Menma/Echo catalogue Skills are later-development possibilities around that already-closed core package. Catalogue presence does not retroactively change Mission 12 or automatically add them to `echo_menma`'s prepared palette.

## 5. Kurama-loan / repeatability boundary

Current Progression authority establishes:

- Mission 12's Kurama loan was voluntary and occurrence-owned;
- temporary projection: `arc1_m12_menma_echo_borrowed_kurama`;
- the loan does not create permanent Kurama Access, ownership, dual-host mastery or permanent Stats/PL;
- `progression_receipt_arc1_m12_coordinated_kurama_loan_experience` records historical experience and may support later repeatability eligibility;
- a later repeat still requires a new legitimate current source/opportunity and Kurama's current voluntary willingness plus any other current relationship/Combat predicates.

Existing loan Actions remain authoritative:

- `arc1_m12_echo_kurama_routed_burst`;
- `arc1_m12_borrowed_kurama_chakra_strike`;
- `arc1_m12_borrowed_kurama_shroud`;
- `arc1_m12_echo_kurama_compensatory_recovery`.

New catalogue Skills that use a Menma + Echo + Kurama three-source route therefore require a **current authorised voluntary Kurama source**. Prior experience alone is never current access.

## 6. General Tailed-Beast / Hosted-Entity boundary

Tailed-Beast/Hosted-source Skills must preserve exact source identity.

A generic catalogue row may describe a reusable technique family, but runtime use requires an exact compatible source relationship. No row implies that every Jinchūriki/host can use every other host's techniques.

Preserve:

- Hosted Entity PL != host PL;
- source participation != second turn;
- hosted presence != independent participant;
- same Tailed-Beast family != same representation;
- same persistent beast != same exact host repertoire;
- relationship synergy != generic multiplier;
- voluntary loan != ownership;
- catalogue row != learned/prepared Skill;
- prior historical access != current source availability.

## 7. Self-cost / forbidden-risk semantics

Some new Kinjutsu rows explicitly spend underlying Remaining Battle PL after a valid committed action. This is exact authored Technique cost, not Injury and not a new universal resource system.

Unless a row explicitly says otherwise:

- cost is applied only after successful action commit;
- invalid/precommit rejection pays no cost and consumes no action;
- cost cannot create a second damage packet against an enemy;
- cost does not alter Base/Current Stats;
- cost history remains attributable to the Technique source;
- reaching zero through an explicitly authored self-cost follows ordinary Battle-PL capability defeat semantics, not automatic death/injury.

## 8. Catalogue vs prepared repertoire

Wave 5 expands the stable Skill library. It does not automatically:

- grant Menma new Skills;
- grant Echo Menma new Skills;
- grant Kurama access;
- grant any Jinchūriki/host a Tailed-Beast Skill;
- alter character Stats/Base PL;
- alter Mission 12's already-closed actions;
- create new Story opportunities;
- create training/mentor rewards;
- implement runtime tables;
- prove Golden/regression.

World/Missions/Training/Progression may later bind exact source/development evidence to these stable Skill IDs without re-authoring their Combat effects.

## 9. Explicitly not closed here

This expansion does **not** close or smuggle in:

- Edo Tensei / reanimation gameplay;
- Complete Return mechanics;
- permanent Echo transfer/extraction systems;
- universal Tailed-Beast extraction;
- generic forced manifestation;
- permanent Menma dual-host power;
- automatic Nine-Tails identity Knowledge;
- universal host-control mechanics.

Those remain under their existing deferred/unresolved ownership until separately authorised.
