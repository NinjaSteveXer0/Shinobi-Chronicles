# Chronicle Dispatch — Dynamic Rumour Count Example

**Date:** 2026-10-06  
**Authority:** #533 / #515  
**Status:** EXAMPLE / REGRESSION CLARIFIER

`2/6` means exactly: two distinct rumours discovered out of six distinct rumours currently issued for that rumour family.

The denominator is dynamic. `6/6` may legitimately become `6/7` if later committed Chronicle history issues a seventh related rumour seed.

Example: a unique Kinjutsu knowledge carrier dies before sharing or recording the knowledge. That exact route can die. If later history creates a legitimate new carrier/source/lead for the same subject, CE may issue a new rumour seed. The six previously found rumours remain discovered history; the family becomes `6/7` until the new rumour is found.

A UI refresh/open/reload can never create the seventh seed.

This example exists to prevent future implementations from misreading `N/M` as evidence completeness, confidence percentage, quest-stage completion, or a permanent hard cap.
