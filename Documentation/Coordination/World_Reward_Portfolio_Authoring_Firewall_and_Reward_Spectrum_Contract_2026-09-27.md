## 1. Why this contract exists

Stephen has identified repeated reward-authoring drift in World / Missions / Events / Rewards:

> materially different player actions are repeatedly being converted into Ryō, often as small additive cash bonuses, while existing Shinobi Chronicles progression, capability, acquisition and Chronicle consequence systems are ignored.

This is not a missing-feature problem.

Current durable authority already supports or preserves many independent consequence/reward channels, including:

- Ryō;
- Items / consumables / materials;
- Weapons;
- Equipment / tools;
- Skills / techniques through exact owner-authorised access/unlock pathways;
- Summons / Familiars / Tailed-Beast access through exact owner-authorised acquisition/access pathways;
- Enhancements / transformations / Hosted-Entity / source-power access through exact owner-authorised pathways;
- the seven persistent development disciplines / Stats:
  - Ninjutsu;
  - Taijutsu;
  - Genjutsu;
  - Bukijutsu;
  - Fūinjutsu;
  - Kinjutsu;
  - Stamina;
- fieldcraft evidence;
- Special Jōnin qualification evidence;
- Knowledge / evidence / intelligence;
- Shared History / relationship consequences;
- reputation / recognition evidence;
- access / permissions / services / training;
- new World opportunity / secret-location / follow-up eligibility;
- event suppression or future route changes;
- recruitment / acquisition / representation eligibility where the correct owner authorises it;
- Chronicle facts and later Story callbacks;
- Shinobi Record / Codex / achievement-style factual record consequences where authorised.

World must author from this real project, not from a reduced economy of:

`Ryō + 3x Kunai`.

This contract does NOT require every occurrence to award every channel.

It requires World to consider the real reward spectrum and choose only causally justified channels.

Canonical rule:

> **Reward diversity means causal diversity, not reward spam.**

# 3. Reward authoring order — MONEY IS NOT STEP ONE

World must author in this order:

```text
committed factual occurrence
-> what did each exact participant actually do?
-> what factual result changed?
-> what development was already earned at action time?
-> what Knowledge / relationship / reputation / access / future-opportunity state changed?
-> what owner-authorised capability/acquisition entitlement is causally justified?
-> what material compensation / Item / Weapon / Equipment is causally justified?
-> only then determine whether Ryō is appropriate
-> commit exact source-scoped receipts
-> presentation
```

Forbidden authoring order:

```text
mission ended
-> choose cash amount
-> add cash to each branch
-> maybe add kunai
```

Canonical:

> **Consequences first. Material reward second. Currency last.**

# 4. Mandatory Reward Spectrum Audit

Before World marks ANY new or revised reward package CLOSED, the author must explicitly evaluate the applicable channels below.

A channel may resolve to:

- `YES — AUTHORISED`;
- `NO — FACTS DO NOT SUPPORT`;
- `OWNER RETURN REQUIRED`;
- `NOT APPLICABLE`.

Silence is not an audit.

## 4.1 Economic compensation

Check:
- Ryō;
- bounty;
- salary / mission fee;
- institutional bonus;
- sale / trade value;
- reimbursement.

Ryō requires an economic or explicitly authored reward reason.

> **Ryō is compensation / currency, not a universal score for “you did well.”**

Tracking well, cooperating, showing courage, noticing a clue, using a Skill correctly or making an interesting choice does not automatically create cash.

## 4.2 Items / consumables / materials

Check:
- medical / recovery consumables;
- field supplies;
- tools;
- crafting materials;
- Fūin Craft materials;
- source-specific consumables;
- exact existing catalogue Items.

World may author an entitlement only for a legal existing definition or after exact owning authority returns a valid definition/source.

No enemy inventory or scenery becomes loot automatically.

## 4.3 Weapons / Equipment / tools

Check:
- exact Weapon entitlement;
- exact Equipment / gear;
- specialist tool;
- training weapon;
- mission-issued or institution-issued equipment;
- provenance-bearing unique reward.

Use only exact owner-authorised definitions.

Ownership != equipped != mastery.

## 4.4 Skills / techniques / capability access

Check whether the factual result legitimately creates:

- Skill access;
- teacher/trainer access;
- scroll / training source;
- technique eligibility;
- source-assisted Skill opportunity;
- mastery-development opportunity.

World does NOT invent Skill mechanics or mastery.

If a Skill is the right reward class but the exact owner contract is missing, preserve the intended Skill/access reward class and route the dependency.

Do NOT replace it with cash.

## 4.5 Summons / Familiars / Tailed Beasts / Hosted sources

Check whether the occurrence legitimately creates:

- Summon contract eligibility;
- Summon acquisition opportunity;
- Familiar relationship/access;
- deployable source access;
- Tailed-Beast encounter/access;
- Hosted-Entity relationship opportunity.

World does not reclassify Tailed Beasts as ordinary Summons and does not grant source ownership from an encounter by implication.

If exact Acquisition/Combat authority is needed, route it.

Do NOT substitute Ryō because the source system is cross-owned.

## 4.6 Enhancements / transformations / source-power development

Check whether the factual route may legitimately create:

- Enhancement eligibility;
- transformation access;
- Curse Mark application/stage opportunity;
- Bloodline development/access where source-authorised;
- Hosted-Entity stage opportunity;
- representation eligibility.

World authors occurrence/opportunity context.

Progression / Combat / Registry / Acquisition own exact persistent/mechanical consequences as applicable.

## 4.7 Seven-discipline / Stat development

For every material Character action, check whether the exact committed action already qualifies under current Progression authority for:

- Ninjutsu;
- Taijutsu;
- Genjutsu;
- Bukijutsu;
- Fūinjutsu;
- Kinjutsu;
- Stamina.

World must NOT replace legitimate action-derived development with money.

World also must NOT directly invent arbitrary `+Stat` points.

Use the existing provenance-bearing action-development pipeline.

Current canonical technical action development remains:

- committed attempt = +1 Development EXP;
- effective execution = +2;
- exact separately-authorised exceptional execution = +3;
- causal caps remain Progression-owned/current authority.

Stat development is participant-specific and action-specific.

Mission completion itself creates no generic Character XP.

## 4.8 Fieldcraft / Special Jōnin evidence

Check whether the factual action demonstrates:

- fieldcraft.stealth_approach;
- fieldcraft.covert_acquisition;
- one exact current Special Jōnin qualification competency;
- another existing authorised specialist evidence family.

Special Jōnin does NOT use generic specialization XP.

World must preserve exact factual evidence for Progression projection.

Examples:
- real tracking may support exact Tracker-nin evidence;
- field stabilisation may support Field Medic evidence;
- seal analysis/execution may support Sealing Specialist evidence;
- exact covert target isolation/execution may support Assassin evidence.

Broad labels are insufficient.

`TRACK` != Tracker-nin automatically.  
`HEAL` != Field Medic automatically.  
`KILL` != Assassin automatically.

## 4.9 Knowledge / evidence / intelligence

Check:
- new observer-bounded Knowledge;
- verified intelligence;
- clue/evidence ownership/custody;
- revealed identity;
- map knowledge;
- source knowledge;
- technique/source observation;
- Shinobi Record update.

Knowledge is often the primary value of investigation content.

Do not pay cash merely because the author forgot that discovering something is already meaningful Chronicle progression.

## 4.10 Relationship / Shared History / reputation / Recognition

Check:
- participant Shared History;
- trust / respect / rivalry / fear / resentment / cooperation facts;
- institutional reputation;
- faction or village Recognition;
- NPC memory;
- teacher/source interest;
- future relationship opportunity.

Do not create generic friendship XP.

Do not convert social/history outcomes into cash by default.

## 4.11 Access / services / permissions / training

Check:
- training facility access;
- trainer/teacher access;
- service-host access;
- shop/service unlock;
- Crafting / Forge / Fūin Craft access;
- restricted-area permission;
- examination/promotion eligibility;
- secret-location eligibility.

Access can be a major reward even when no Item changes hands.

## 4.12 Future World / Story / CE opportunity

Check:
- new hotspot/event family eligibility;
- history-generated follow-up;
- secret location;
- rare encounter;
- recruitment/acquisition route;
- relationship continuation;
- optional side arc;
- later Story recognition;
- event suppression / prevention;
- alternate resolver availability.

A future opportunity is not “nothing”.

It can be one of the most valuable Chronicle outcomes.

## 4.13 Acquisition / roster / representation eligibility

Where factually appropriate, check:
- recruitability;
- ownership entitlement;
- representation eligibility;
- Evolution entitlement;
- transformation representation eligibility;
- source/Character acquisition opportunity.

World does not commit ownership unless exact Acquisition authority says it owns that transaction.

## 4.14 Chronicle Engine factual consequence

Every meaningful occurrence must finally ask:

> **What is now true in this Chronicle that was not true before?**

Possible answers include:
- someone remembers the player;
- an enemy escaped;
- a witness survived;
- a route closed;
- a secret is known;
- a source became interested;
- an institution now recognises a capability;
- a future encounter changed;
- a relationship changed;
- a place became discoverable;
- a power source became eligible;
- a Story callback now has different material.

This factual history must not be discarded merely because it is not loot.

# 5. Hard anti-Ryō rules

## 5.1 Ryō cannot be the universal praise currency

Do not award cash merely to represent:

- tracking;
- cooperation;
- bravery;
- curiosity;
- mercy;
- aggression;
- use of a discipline;
- cleverness;
- Story engagement;
- reflection choice;
- “good performance” without a paying source.

If an Academy exercise, village institution, employer, bounty office or other source explicitly pays performance bonuses, author that economic source clearly.

The performance may still independently create development / evidence / history.

## 5.2 Currency-fragmentation smell test

If several materially different route facts are each being converted into small Ryō increments, STOP and re-audit.

Example smell:

- tracking = +25 Ryō;
- cooperation = +25 Ryō;
- intercept = +25 Ryō;
- secondary incident = +25 Ryō.

Those facts are semantically different.

They should first be examined for:
- tracker evidence;
- technical development;
- Shared History;
- Knowledge;
- institutional recognition;
- access;
- future opportunity;
- exact material/economic compensation.

A package may still contain some Ryō after this audit.

It must not use identical cash increments as a substitute for designing actual consequences.

## 5.3 Ryō-only reward packages require affirmative justification

A Ryō-only package is legal only when World records why:

1. direct economic compensation is the actual intended value; and
2. no additional already-authorised consequence/development channel is supported by the facts, OR those channels are already independently committed and acknowledged; and
3. no missing owner dependency is being hidden by the cash payout.

“Simple”, “easy to implement” and “owner not available yet” are invalid reasons.

This is binding.

- a Skill;
- Summon;

- special Item;
- representation;
- transformation access;
- Tailed-Beast/source access;
- specialist training;
- exact development consequence;
- Special Jōnin evidence;
- recruitment/acquisition opportunity;

and exact owner authority is missing:

> **World must preserve the intended reward class and route the missing owner dependency.**

World may NOT silently replace it with:

- Ryō;
- generic kunai;
- generic healing items;
- an unrelated catalogue object.

Exact already-authored fallback rules remain valid where a current durable contract explicitly defines them, such as a specific reward-pool fallback.

There is NO global “if unavailable, pay cash” rule.

---

# 7. HARD RULE — NO FILLER LOOT

Generic low-value Items must not be added merely to make a reward list look varied.

Examples of invalid reasoning:

- “give 3 Kunai because we need an item”;
- “add a potion to every mission”;
- “add random material because cash alone looks boring”.

An Item/Weapon/Equipment reward must have a causal source and gameplay purpose.

Legitimate examples can include:
- Academy-issued training tool;
- ANBU-issued specialist equipment;
- medical resupply after exact field duty;
- recovered unique object transferred through legitimate ownership;
- crafting material from an exact source;
- mission employer supplying necessary gear;
- rare source-specific item.

Diversity != junk.

---

# 8. HARD RULE — DIVERSE DOES NOT MEAN MAXIMAL STACKING

This firewall must not cause the opposite failure where every event gives everything.

One factual source may legitimately support multiple channels only when each channel records a different true consequence.

Example:

a successful authored tracking/intercept occurrence might legitimately create:
- exact Tracker-nin evidence;
- new Knowledge of a route;
- relationship/reputation history with the instructor;
- access to a later tracking opportunity;
- an institutional cash bonus if the Academy actually pays one.

It does NOT automatically grant:
- Ninjutsu EXP;
- a Weapon;
- a Summon;
- an Enhancement;
- a Skill;
- a promotion.

Every channel still needs causal support.

# 9. Action-time development != debrief material reward

World must actively check occurrence-time development before authoring debrief material rewards.

If a Character earned:
- Discipline Development EXP;
- Stamina development;
- fieldcraft evidence;
- Special Jōnin evidence;
- exact relationship/history;
- Knowledge;

that value remains true even if the mission later fails.

The debrief does not recommit it.

Likewise, the existence of action-time development does not forbid a separately justified material reward.

They are separate channels.

---

# 10. Battle rewards and World rewards remain separate

Battle victory may have an exact immediate reward where specifically authored.

World/Story completion may have separate deferred rewards.

Do not infer:

- per-enemy money;
- generic loot;
- generic Character EXP;
- mission success;
- custody;
- assassination development.

0 Battle reward does not mean 0 development/history.

A Battle can legitimately grant no material loot while its executed actions create substantial development evidence.

---

# 11. Duplicate / already-owned reward handling

Already owning a reward object does not author a universal automatic cash conversion.

Use the exact owning system's duplicate/singleton semantics.

If no duplicate policy exists:
- preserve the entitlement;
- route the owner gap;
- do not invent compensation.

No generic duplicate-to-Ryō economy exists.

---

# 12. Failure / partial success / non-action

Preserve:

- Battle loss != mission failure;
- mission failure != zero value;
- partial success != universal consolation cash;
- non-action can be legitimate Chronicle history;
- failure may preserve training, evidence, Knowledge, relationships, survivors, leads or future opportunities.

Do not pay “sorry money” merely because a route would otherwise show no material reward.

---

# 13. Choice neutrality / no morality payout

Do not monetise a moral judgement.

Examples:

- intervene != automatically more reward;
- keep pursuing != punishment;
- call for help != cowardice;
- kill != bounty unless an actual bounty/source authorises it;
- restrain != universally virtuous bonus;
- release != universally lesser reward.

Different actions can produce different consequence classes without ranking the player's morality.

# 14. Reward portfolio anti-monotony review

Before closing an Origin, Mission batch, Event family or Arc reward set, World must compare the current package against nearby content.

Ask:

- Are most rewards cash?
- Are most item rewards the same consumable?
- Are Skills/Summons/Enhancements/Equipment never used despite authored systems?
- Are capability-heavy routes receiving only money instead of development/evidence/access?
- Are exploration/investigation routes receiving money instead of Knowledge/discovery?
- Are relationship routes receiving money instead of Shared History/future opportunity?
- Are specialist routes receiving cash instead of exact evidence/training/access?
- Are all failures being treated as 0 or consolation money?

There is no fixed quota.

However:

> **systematic repetition is a design-smell that must be justified, not the default.**
