# Shinobi Chronicles — Expected History vs Recorded History Chronicle Divergence Doctrine

**Date:** 2026-09-12  
**Owner:** CE / Codex / Coordination  
**Status:** **BINDING CE / CODEX DOCTRINE — REINFORCEMENT / NO NEW RUNTIME SYSTEM**

---

## 1. Core rule

> **Expected History != Recorded History.**

**Expected History** is the baseline/canon trajectory, historical expectation, authored prior, or world assumption describing what would ordinarily be expected to have happened absent a legitimate Chronicle divergence.

**Recorded History** is what this Chronicle has actually committed as factual occurrence history.

When the two diverge, runtime truth follows **Recorded History**.

Expected History may remain useful for:

- establishing historical expectation;
- creating surprise, contradiction or investigation pressure;
- informing what an observer reasonably believed before new evidence;
- providing authored campaign context;
- identifying that a divergence event occurred.

Expected History must not overwrite, erase or silently normalize a legitimate committed divergence.

---

## 2. Divergence does not erase prior history

A later divergence may change the current state without deleting the factual events that came before it.

Canonical form:

`expected state/history`
→ `factual occurrence`
→ `later divergence occurrence`
→ `new factual current state`

The Chronicle preserves every committed factual transition that still belongs to history.

Therefore:

- current state != entire historical record;
- later reversal != earlier event never happened;
- restoration != retcon;
- resurrection != death erased;
- reconciliation != conflict never happened;
- release != captivity never happened;
- cure != illness never happened;
- Promotion != lower Rank history never happened.

---

## 3. First / Second Hokage application

Naruto baseline/canon expectation says Hashirama Senju and Tobirama Senju are dead in the relevant later historical period.

Shinobi Chronicles Recorded History is different:

1. Hashirama genuinely died.
2. Tobirama genuinely died.
3. Those deaths remain factual Recorded History.
4. A later divergence event genuinely restored each to living state.
5. The restoration was **not Edo Tensei**.
6. Each remains the same persistent person.
7. Their current living state is therefore also Recorded History.

The correct Chronicle history is:

`alive -> genuine death -> dead historical state -> genuine non-Edo resurrection -> alive current state`

not:

`they never died`

and not:

`canon says dead, therefore current living state must be ignored`.

This application consumes:

`Documentation/Coordination/First Second Hokage Non-Edo Living Resurrection Canon and Discovery Boundary 2026-09-12.md`

The exact resurrection mechanism, performer, timing, cost, reproducibility and body/age consequences remain protected canon gaps under that authority.

---

## 4. World Truth and observer expectation

Expected History may legitimately exist inside the fiction as an observer belief or institutional historical assumption.

An observer may believe:

> `The First Hokage is dead.`

because that is the historical record available to them.

If Hashirama has in fact returned to life but that fact is not yet known to the observer, then:

- World Truth = Hashirama is currently alive;
- Recorded History = Hashirama died and was later resurrected;
- observer Knowledge = may still contain only the death;
- observer belief/expectation = he remains dead;
- presentation must reflect only what that observer is authorised to know.

Therefore:

> **Expected History != Recorded History != observer Knowledge != presentation.**

A contradiction between expectation and new evidence is a legitimate Story/World pressure, not an excuse to rewrite the Chronicle.

---

## 5. Story / World authoring rule

When Story or World uses baseline canon/history:

1. treat it as an authored prior/expectation;
2. query current Recorded History before asserting present truth;
3. preserve legitimate divergence occurrences;
4. allow characters/institutions to be surprised or wrong where their Knowledge warrants it;
5. never silently force the Chronicle back onto expected canon because a divergence is inconvenient;
6. never invent the missing causal explanation for a divergence merely to make it resemble expected history.

A divergence can become a mystery.

It does not become an error merely because expected canon disagrees with it.

---

## 6. Runtime / Codex implication

No new engine is authorised by this doctrine.

Existing Chronicle occurrence/history semantics are sufficient if runtime preserves:

- committed factual occurrences;
- current factual state;
- provenance linking state changes to occurrences;
- observer-relative Knowledge;
- deterministic replay/reconstruction of committed history.

Codex/Story/World projections must consume Recorded History rather than deriving current truth from a static canon expectation table.

If Expected History and Recorded History conflict, presentation may expose the contradiction only to observers who have legitimate evidence of it.

---

## 7. Hard non-collapse rules

Preserve:

- Expected History != Recorded History;
- baseline canon != runtime factual truth automatically;
- current state != complete historical record;
- divergence != retcon;
- later reversal != earlier occurrence erased;
- World Truth != observer Knowledge != presentation;
- observer expectation != World Truth;
- historical record available to observer != complete Chronicle history;
- Story surprise != permission to fabricate explanation;
- protected canon gap != blank space for improvisation;
- committed factual history is replayed/reconstructed, never rerolled.

---

## 8. Canonical shorthand

> **Canon tells us what history was expected to be. The Chronicle records what actually happened. When a legitimate divergence changes the world, we keep both the history that happened before it and the divergence that changed what came next.**
