## Core doctrine

- location != event != opportunity;
- eligibility precedes selection;
- randomness only among already-eligible possibilities;
- mandatory Story != standing free-play pool;
- Battle is a resolver, not mission ontology;
- non-action / decline / observation / withholding / leaving unresolved is attributable Chronicle history, not a morality or progression penalty;
- different decisions may produce different reward families rather than simply more/less currency;
- reward eligibility consumes committed history and never rerolls on UI refresh/load;
- World may author reward entitlement/context, but exact Items/Weapons/Skills/Summons/representations remain within their owning domains;
- special-card, Summon and tailed-beast hooks create eligibility/leads only until the owning system authorises the exact grant;
- authored seed != implemented != runtime validated != Golden GREEN.

## Production strategy

500 authored seeds were a content-reservoir target, **not an Alpha implementation mandate**. Alpha should activate coherent high-value slices through the existing mission/event/opportunity architecture. The remainder stays as authored reserve so the world can expand without inventing content ad hoc.

Each activated row still requires:

1. exact host address / current map calibration;
2. exact occurrence identity and factual commit boundaries;
3. semantic eligibility;
4. observer Knowledge / discovery / actionability;
5. participant/object source authority;
6. reward entitlement and idempotent grant rules;
7. any exact Combat / Progression / Acquisition / Registry dependencies;
8. save/load persistence and no reroll/duplication;
9. runtime/browser validation before GREEN.
