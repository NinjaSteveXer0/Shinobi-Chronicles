# Shinobi Chronicles — Multi-Path Capability Synergy Expansion and Combination Authoring Matrix v1

**Date:** 2026-09-12  
**Owner:** World / Missions / Events / Rewards  
**Status:** **BINDING WORLD AUTHORING AUTHORITY — CONTENT MATRIX; IMPLEMENTATION / EXACT CAPABILITY SEMANTICS REMAIN OWNER-BOUND**

## 1. Purpose

This document expands the capability-responsive World/Event ecology beyond single-path and simple two-path examples.

The design target is not to enumerate every mathematical combination of disciplines, Skills, specialisations, relationships, Knowledge and Chronicle history. That would create an artificial combinatorial checklist.

The design target is:

> **Author combinations only where two, three or occasionally four independently legitimate routes together create a factual affordance, risk, outcome or future chain that none of them creates as naturally alone.**

Canonical principles remain:

- something for everyone != everything for everyone;
- more capabilities = deeper eligible possibility space, not automatic event spam;
- specialist eligibility != automatic success;
- combined route != guaranteed superior route;
- different build != same reward with different flavour text;
- capability possession != event spawn;
- eligibility precedes selection;
- World Truth != Knowledge != presentation;
- Knowledge != Access != Competence != Power != Mastery;
- Battle victory != Story outcome automatically;
- loss/failure does not erase legitimate evidence/history already produced;
- non-action may create factual Chronicle history without morality scoring.

This extends:

- `Capability Responsive Chronicle Event Ecology v3`;
- CE `Capability Responsive Story Outcome Families and Cross-Discipline Affordance Contract`;
- World `Capability Responsive Story Affordance and Outcome Consumer Pack v1`.

## 2. Combination classes

### 2.1 Pair synergy

Two independent route families together create a stronger or qualitatively different factual affordance.

Typical World use: 2–6 authored consumers across the campaign for important combinations.

### 2.2 Triad synergy

Three independently proven paths create a rare Chronicle intersection.

These should be uncommon and highly contextual. They may justify dedicated events/chains another Character never sees.

Typical World use: 1–3 authored consumers for meaningful triads, not every possible trio.

### 2.3 Rare multi-path convergence

Four or more routes may create exceptional bespoke opportunities where prior Chronicle history genuinely supports the premise.

These are not stronger because they use more tags. They are rarer because the factual situation requires an unusual person/history.

## 3. Taijutsu + Genjutsu — expanded flagship pair

This pairing is explicitly legitimate and should receive more than one consumer.

Possible factual affordances:

1. **Real Body, False Room** — Genjutsu identifies which perceived position/evidence is false; Taijutsu allows the protagonist to physically reach/control the real operator before they escape.
2. **Witness Under Distortion** — Genjutsu separates induced perception from the witness's actual sensory input; Taijutsu supports safe restraint/extraction when the witness panics or lashes out.
3. **Close-Range Counter-Deception** — Genjutsu awareness prevents committing to a false opening; Taijutsu turns the surviving physical opening into capture, disarm or protection rather than necessarily lethal defeat.
4. **Protect the Target, Break the Illusion** — Taijutsu maintains physical protection/position while Genjutsu capability helps identify which apparent attackers/threats are genuine.
5. **Controlled Interrogation Pressure** — where exact Genjutsu technique and consent/context permit, Genjutsu changes observer perception while Taijutsu provides physical security; this may preserve a living source but can also create institutional/relationship consequences.
6. **Illusion-Layer Pursuit** — Genjutsu detects route falsification while Taijutsu preserves pursuit through dangerous close geometry.

Possible outcome families:

- living witness preserved;
- suspect captured rather than killed;
- clean testimony vs contaminated testimony;
- observer Knowledge about the protagonist's Genjutsu use;
- specialist-development evidence where authorised;
- later counter-Genjutsu contact/training chain;
- target escapes because the protagonist prioritised witness safety.

Taijutsu does not grant impossible movement or guaranteed restraint. Genjutsu does not grant mind reading or perfect truth extraction.

## 4. Ninjutsu + Bukijutsu + Kinjutsu — high-risk field-control triad

This triad is legitimate where all three exact routes are independently established.

The intended fantasy is not `three high stats = super attack`.

It is:

- Ninjutsu changes field/environment/position through exact techniques;
- Bukijutsu provides exact tool/weapon precision, delivery, disarm, cutting, trap or equipment interaction;
- Kinjutsu Knowledge/competence allows recognition, controlled interaction or risk assessment around forbidden methods only where exact owner authority permits.

Possible authored consumers:

1. **Forbidden Relay Interdiction** — Ninjutsu isolates the physical route/power/terrain, Bukijutsu cuts or pins the exact mechanical line, Kinjutsu identifies which component must not be ruptured. Outcome may preserve evidence another route destroys.
2. **Weaponised Containment Site** — Ninjutsu changes terrain so a dangerous object cannot spread/escape; Bukijutsu manipulates the physical restraint; Kinjutsu recognises the forbidden reaction risk.
3. **The Technique Hidden in the Weapon** — Bukijutsu recognises unusual weapon construction, Kinjutsu identifies forbidden method provenance, Ninjutsu permits safe environmental testing/containment rather than immediate activation.
4. **Controlled Denial Rather Than Destruction** — exact Ninjutsu and weapon actions disable a hostile system while Kinjutsu warns which seemingly obvious destruction route would produce a worse state.
5. **Pursuit Through a Forbidden Hazard** — Ninjutsu opens/traverses the environment, Bukijutsu protects/cuts a route, Kinjutsu identifies dangerous residues/conditions; the protagonist may reach a source another build loses but risks exposure or contamination.
6. **Recover the Instrument, Not Just the Target** — Battle can end with target neutralised, but this triad may additionally preserve a forbidden tool/weapon with provenance for later analysis instead of destroying it.

Potential consequences:

- preserved vs destroyed infrastructure;
- recovered vs contaminated evidence;
- dangerous object custody;
- future weapon/crafting lead;
- Kinjutsu observer suspicion/recognition;
- alternate route access;
- later obligation because the protagonist retained something dangerous.

High Kinjutsu alone does not invent a forbidden Technique. Exact capability authority is still required.

## 5. Assassination + Taijutsu + Fūinjutsu — covert control / neutralisation triad

**Authority caution:** `Assassination` is treated here as a candidate specialist/service-history family, not a newly invented Skill ID. Runtime eligibility must bind only after the owning Progression/Skills/Registry authority confirms the exact durable predicate(s) that constitute legitimate Assassination capability/qualification.

If that route is legitimately present, this triad is exceptionally fertile.

Possible factual consumers:

1. **No Alarm, Living Target** — Assassination fieldcraft provides approach/timing, Taijutsu provides close non-lethal control, Fūinjutsu applies an exact authorised restraint/suppression/containment method. Outcome: living source secured before alarm, but use of a distinctive seal may leave evidence of who intervened.
2. **Marked Exit** — covert route establishes the target's likely extraction line, Taijutsu intercepts physically, Fūinjutsu blocks/seals the specific exit or object route. Target may surrender, fight, escape through another path or destroy evidence.
3. **Silent Courier Seizure** — approach without public Battle, physical restraint, then exact seal custody on the dispatch/container rather than the person. This can preserve both courier and evidence but may sacrifice pursuit of a second actor.
4. **Kill Opportunity / Capture Choice** — Assassination history makes a lethal opening possible; Taijutsu/Fūinjutsu together create an alternate capture/containment option. The important Chronicle result is not morality but what factual state the player chooses to create.
5. **Seal the Signal Before the Strike** — Fūinjutsu identifies/blocks an alarm or transmission mechanism while fieldcraft creates the window and Taijutsu controls the operator. Failure can still commit that the signal was delayed, partially sent or its method discovered.
6. **Bodyguard Bypass Without Murder** — assassination route reaches the principal, Taijutsu handles close obstruction, Fūinjutsu isolates a weapon/door/route. Result may create institutional fear or respect because the protagonist demonstrated they could have killed someone and chose another outcome.
7. **Extraction Under Identity Pressure** — covert operation succeeds physically, but observer Knowledge of the protagonist's seals or fighting style may compromise anonymity and generate a later counter-intelligence chain.

Possible consequences:

- live custody instead of corpse;
- target escaped but signal/evidence preserved;
- secret route exposed;
- covert reputation / institutional concern;
- Special Jōnin qualification evidence if the exact actions map to authorised competencies;
- later counter-surveillance or retaliation event;
- relationship effects from choosing capture, release, kill where Story authority permits, or withdrawal.

Assassination != guaranteed kill, invisibility, universal stealth or permission to kill. Fūinjutsu != generic chakra shutdown. Taijutsu != guaranteed restraint.

## 6. Additional high-value pair synergies

### Tracking + Sensory
Physical trail chronology plus current presence/chakra disturbance. Can distinguish where a trail ended from where a source currently is without granting identity.

### Tracking + Counter-Surveillance
Recognise that the protagonist is being led, watched or fed a false trail; may create a reverse-tail chain.

### Tracking + Medical
Injury mechanics + movement trace can establish likely pace/direction or whether someone was carried, without revealing exact identity.

### Tracking + Summon
Relationship-authorised distributed search, scent/local-knowledge or terrain traversal. Summon may refuse or interpret independently.

### Sensory + Genjutsu
Distinguish sensed presence from presented appearance; useful for proving an inconsistency without automatically exposing the technique user.

### Sensory + Fūinjutsu
Differentiate suppression/barrier effect from what may exist behind/inside it; does not open the seal.

### Sensory + Hosted Entity
The protagonist and hosted source may perceive different aspects of the same pressure; relationship determines whether the source shares interpretation.

### Medicine + Fūinjutsu
Stabilise a patient while recognising/securing a seal-mediated condition; can preserve both life and evidence.

### Medicine + Kinjutsu
Recognise that forbidden methodology is affecting a patient, preserve tissue/residue/evidence, and avoid contaminating a later investigation.

### Medicine + Taijutsu
Physical extraction/rescue under hazard plus legitimate stabilisation; may save someone while allowing hostile escape.

### Genjutsu + False Identity
Control of perceived context plus recognised-profile manipulation can create sophisticated observer-history contradictions; neither rewrites World Truth.

### Genjutsu + Counter-Surveillance
Detect/manipulate perception of a watcher or decoy network without becoming universally invisible.

### Bukijutsu + Counter-Surveillance
Identify weapon/tool placement that implies hidden observation or interception geometry; may disable the tool while preserving provenance.

### Bukijutsu + Crafting
Recognise failure/construction and perform exact owner-authorised repair/modification; can create provenance-bearing item history.

### Bukijutsu + Rare Knowledge
Recognise a weapon/tool as historically important when others see ordinary scrap.

### Ninjutsu + Tracking
Use exact environmental techniques to expose/preserve trace evidence or deny escape without inventing a new tracking Skill.

### Ninjutsu + Fūinjutsu
Field manipulation plus seal/barrier work can isolate an area, preserve infrastructure or create alternate containment.

### Ninjutsu + Summon
Exact technique plus summon identity/capability may create traversal, rescue or environmental solutions neither route supports alone.

### False Identity + Political Recognition
A recognised public role collides with a legitimate false profile. This can generate scrutiny, leverage, obligation or contradiction rather than automatic success.

### False Identity + Underworld History
Different networks legitimately know different profiles; later collisions can become dedicated Chronicle chains.

### Bloodline + Clan History
Active capability reveals something unusual; historical Knowledge explains significance. Latent Bloodline potential alone does nothing.

### Bloodline + Counter-Surveillance
Exact perception/field capability may notice surveillance geometry another character misses, but observer Knowledge can also expose the Bloodline.

### Summon + Fūinjutsu
A summon can provide location/relationship-specific assistance while Fūinjutsu handles seals/contracts/barriers only where exact authorities allow. Summon presence does not equal seal authority.

### Hosted Entity + Fūinjutsu
Host relationship creates a living source/context; Fūinjutsu may inspect/manage exact containment/interface conditions without implying command or ownership.

### Hosted Entity + Kinjutsu
Rare and risky: forbidden-method Knowledge may recognise exploitation/recall/alteration pressure affecting the hosted relationship; using that Knowledge may itself create institutional concern.

### Political Recognition + Rare Knowledge
The protagonist knows the right fact and possesses a lawful channel to raise it, creating access/audience another build lacks.

### Service Recognition + Underworld History
Two observer networks know different roles/history; may create duty conflict, leverage or suspicion.

## 7. Additional triad synergies

### Tracking + Sensory + Counter-Surveillance
`The Trail That Watches Back` — physical pursuit, current-presence sensing and watcher detection establish that the target route is also an observation net. Outcome choices include reverse-tail, abort, feed misinformation, expose watcher or continue knowingly.

### Genjutsu + False Identity + Underworld History
`Three Versions of the Same Person` — an underworld network, a current observer and an official record each know different versions of the protagonist. The event is about managing contradictory observer histories, not rewriting identity.

### Medicine + Fūinjutsu + Kinjutsu
`The Living Seal Case` — patient survival, seal-mediated condition and forbidden-method provenance intersect. The player may prioritise life, evidence, containment or disclosure with different consequences.

### Ninjutsu + Fūinjutsu + Barrier Recognition
`Hold the Breach` — exact Ninjutsu changes environmental pressure, Fūinjutsu acts on a legitimate seal/barrier state, recognition identifies the safe subsystem. May preserve a site another route loses.

### Tracking + Bukijutsu + Weapon Provenance
`Marks Left by the Wrong Blade` — route evidence plus cut/impact signatures plus provenance Knowledge identify that a distinctive weapon class was involved without proving wielder identity.

### Taijutsu + Medicine + Rescue History
`Carry Them Through` — physical control/extraction plus treatment plus prior rescue trust can keep a frightened/injured participant cooperative during a dangerous withdrawal.

### Summon + Tracking + Sensory
`Search Beyond One Body` — distributed search using exact summon capability, trail evidence and sensory observations; relationship and terrain can create conflicting reports requiring interpretation.

### Bloodline + Clan History + Political Recognition
`The Thing Your Clan Wasn't Supposed to See` — active Bloodline capability reveals a fact; clan history explains it; political recognition determines whether the protagonist can lawfully act or must choose secrecy/obligation.

### Bukijutsu + Crafting + Material Provenance
`The Weapon That Can Be Saved` — expertise recognises construction, Crafting enables exact authorised repair, provenance Knowledge identifies why preserving original material matters.

### False Identity + Counter-Surveillance + Fūinjutsu
`A Name, a Tail, and a Ward` — the watcher records the wrong recognised identity while a seal layer also records a profile/provenance trace. The protagonist can preserve one deception while exposing another, creating rich later contradiction history.

### Assassination + Tracking + Counter-Surveillance
`Hunter / Hunted` — specialist approach and target pursuit reveal a hostile surveillance net following both parties. The protagonist may complete objective, reverse-tail, protect anonymity, capture observer or abandon pursuit.

### Assassination + Genjutsu + False Identity
`The Person Nobody Saw` — legitimate covert approach, exact perception manipulation and recognised-profile substitution create a near-perfect observer discrepancy, but physical evidence and prior Knowledge can still survive and generate future investigation.

### Assassination + Bukijutsu + Poison/Medical Knowledge
`One Cut, Three Meanings` — specialist delivery opportunity, weapon expertise and toxicological Knowledge permit kill/capture/sample/preserve-evidence branches where Story allows. No universal poison creation or assassination permission is implied.

### Fūinjutsu + Hosted Entity + Tailed-Beast Relationship
`The Seal Is Not the Relationship` — exact seal state, hosted relationship and Beast willingness are separate. A crisis can be solved through cooperation, containment, negotiation, temporary access or refusal; none automatically creates ownership or permanent power.

### Kinjutsu + Echo Relationship + Recall Awareness
`Do Not Pull` — forbidden-method Knowledge, Echo relationship and compatible recall-pressure awareness create a route to recognise/interpret dangerous retrieval pressure. Outcome may preserve relationship, evidence or autonomy at another cost.

## 8. Rare four-path convergence examples

These should be exceptional and history-heavy.

### False Identity + Counter-Surveillance + Fūinjutsu + ANBU/service Knowledge
`The Door That Knows the Wrong Operative`

A secure route recognises a false profile, a surveillance system tracks movement, a ward records provenance, and the protagonist knows enough institutional procedure to understand what should happen next. Possible outcomes include controlled infiltration, deliberate exposure, planted contradiction, evidence preservation or abort.

### Tracking + Sensory + Medicine + Summon
`Find Them Before They Become a Body`

Trail, current presence, likely injury condition and relationship-authorised distributed search combine during a time-sensitive rescue. Success is not automatic; the combination changes reach and information quality.

### Ninjutsu + Bukijutsu + Fūinjutsu + Crafting
`Keep the Machine Alive`

Environmental control, precision tool use, seal interaction and exact Crafting authority can stabilise/repair a complex site instead of merely destroying it, potentially creating future service access or dangerous ownership/obligation questions.

### Assassination + Taijutsu + Fūinjutsu + False Identity
`Take Them Without Existing`

Where all exact predicates are legitimate, the protagonist may approach under a recognised false profile, physically control the target, use exact seal custody/containment, and exfiltrate without an open Battle. This can create an extraordinary observer-history puzzle later; it is not a universal perfect stealth route.

## 9. Reward / consequence design for combination content

Multi-path content should often reward **qualitative history** more than raw payout.

Possible channels:

- living witness/custody;
- preserved evidence/provenance;
- alternate access;
- recovered weapon/material;
- future Forge/Fūin Craft opportunity;
- institutional recognition or suspicion;
- underworld relationship;
- clan/service obligation;
- Knowledge;
- observer-specific identity history;
- specialist-development evidence where authorised;
- new mentor/contact;
- later compound event eligibility;
- secret-location suspicion/discovery;
- changed location/object state;
- avoided Battle;
- different Battle-to-Story result;
- unresolved pressure deliberately retained.

No combination is entitled to a numerically better reward merely because more predicates were required.

## 10. Authoring density rule

Do **not** generate a quest for every theoretical pair/trio.

For each newly closed expressive route, World should evaluate:

1. 2–6 strong pair synergies with existing major routes;
2. 0–3 triad synergies where a genuinely new premise exists;
3. rare four-plus convergence only for history-rich Chronicles;
4. at least one potential history-generated follow-up where the combined action would create memorable future state;
5. whether an existing event should gain a branch instead of authoring a new event;
6. whether the candidate belongs in Alpha activation, Alpha reserve or post-Alpha reserve.

The 500+ reservoir may grow beyond 500 as these synergies become worth authoring.

## 11. Ownership boundary

World authors the factual opportunity and exact eligibility consumer.

World must not invent:

- a new Skill just to support a route;
- Technique ownership;
- Bloodline access;
- Summon obedience;
- Hosted Entity cooperation;
- Special Jōnin qualification semantics;
- Assassination predicate/qualification if not yet durably owned elsewhere;
- exact Combat effects;
- Progression grants;
- item/weapon/crafting recipe authority.

If an authored consumer requires one of those exact unresolved semantics, create a focused owner handoff only then.

Until then these combinations are World authoring families, not free capability grants.
