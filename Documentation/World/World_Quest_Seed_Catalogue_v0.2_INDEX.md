## 7. Activation boundary

A seed row is not automatically executable.

Before promotion, the normal World activation bar still requires:

- exact current host identity / calibrated geometry;
- exact eligibility and absence predicates;
- participant/object bindings;
- Knowledge/discovery/actionability projection;
- actions and factual outcome envelope;
- recurrence/expiry/suppression/non-action handling;
- exact reward or explicit no-material-reward authority;
- owning-system dependencies where any;
- occurrence persistence/idempotence;
- implementation and runtime/browser validation separately.

Current non-Fire regional maps and non-Konoha village maps have committed artwork masters but do not all have the same mature exact hotspot calibration as Fire/Konoha. Their Wave-2 rows therefore remain valid **reservoir content** while awaiting exact host calibration for whichever slices are promoted into Alpha.
