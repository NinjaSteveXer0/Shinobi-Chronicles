# Shinobi Chronicles — Great Country Regional Map Revamp World Geography Preservation Contract

**Date:** 2026-09-09  
**Owner:** World / Missions / Events / Rewards  
**Consumer:** UI / Assets first; World calibration second; Coding only after final bindings  
**Status:** **PRE-GENERATION WORLD GEOGRAPHY CONTRACT — FIRE REQUIRED NOW / OTHER GREAT COUNTRIES APPLY SAME MODEL**

---

## 1. Purpose

Fire, Earth, Wind, Lightning and Water are being visually regenerated before deep regional hotspot/runtime integration.

The goal is not merely prettier regional art. Each master must provide a dense reusable geographic vocabulary capable of hosting Story, standing events, side quests, investigations, training, discoveries, secrets, travel incidents, NPC encounters and future Chronicle-sensitive content without forcing a new map image every time World authors something.

Locked responsibility split:

> **terrain artwork = geographic world truth / reusable spatial affordance**

> **World = location / event / opportunity meaning**

> **UI/runtime = marker / Knowledge / discovery / access / hover / focus / current presentation state**

Preserve:

> location != hotspot != event != opportunity

> stable semantic identity != pixel coordinate

> map revision != semantic reroll

> concealed world truth != visually obvious landmark

> route geography != fixed quest bucket

---

## 2. Existing authority when artwork changes

`Documentation/Maps/Regional Map Source Binding Ledger.md` remains correct:

> calibration coordinates != artwork-independent truth

A new regional master invalidates old coordinates, hit regions and route splines until revalidated.

It does **not** automatically invalidate durable World identities already consumed by Story, World content or runtime.

For every new master:

1. preserve durable semantic identities required below;
2. discard old pixel authority;
3. generate the new terrain with sufficient physical hosting capacity;
4. UI / Assets commits the final exact binary;
5. World + UI recalibrate anchors, interaction regions and routes against that binary;
6. Coding consumes only the final promoted geometry.

Do not force the new artwork to copy old coordinates or old composition merely to preserve identities.

# 3. LAND OF FIRE — STRONGEST PRESERVATION REQUIREMENT

Land of Fire already has active World/event authority using the country-scoped authoring namespace:

- `fire:P##` public/major destination
- `fire:SV##` service presentation anchor
- `fire:O##` optional destination
- `fire:S##` concealed/event reservation
- `fire:R##` travel corridor
- `fire:Z##` broad regional territory

These IDs now function as durable authoring addresses. **They must survive the visual revamp.**

What changes:

- coordinates;
- interaction rectangles;
- route control points;
- exact visual placement;
- relative micro-layout where the new terrain composition benefits.

What does not silently change:

- semantic identity;
- public / optional / concealed role;
- event-family host relationships already authored;
- discovery / Knowledge semantics;
- existing occurrence history.

Do not recycle an existing Fire ID for a different place merely because the old coordinates are being discarded.

# 4. EARTH / WIND / LIGHTNING / WATER — PRESERVATION RULE

These four countries do **not** currently have the same level of Alpha World-content dependency on their old calibrated geometry as Fire.

Therefore:

1. The Hidden Village identity is mandatory and must be physically represented as a major man-made landmark:
   - Land of Earth → Iwagakure
   - Land of Wind → Sunagakure
   - Land of Lightning → Kumogakure
   - Land of Water → Kirigakure
2. Any durable named location already referenced by Story/World/Coding must survive semantically.
3. Legacy v1 coordinate placements are **not** a reason to distort the new art.
4. Old purely geometric/unconsumed reservation slots are not automatically sacred semantic canon.
5. After the final master is selected, World will publish/promote the country-specific v2 semantic/hosting set and UI will calibrate its geometry.
6. Use the same namespace model for consistency:
   - `{country}:P##`
   - `{country}:SV##`
   - `{country}:O##`
   - `{country}:S##`
   - `{country}:R##`
   - `{country}:Z##`
7. Do not reuse a legacy ID for a conflicting identity. If an old named identity is intentionally retired, retain that fact in provenance rather than silently repurposing the number.

# 5. REQUIRED CLICKABLE-GEOGRAPHY DENSITY

A final Great-Country master is **not World-authoring ready** merely because it contains five beautiful landmarks.

World wants each regional master to provide at least approximately **40 distinct hotspot-capable terrain contexts**, with **50–60 preferred** where the composition supports it without visual clutter.

This does not mean 60 simultaneous markers.

It means 40–60 places where a future contextual marker/opportunity could be anchored without looking arbitrary.

### Minimum vocabulary per country

Before final acceptance, aim for terrain capable of supporting approximately:

- **8–12 major/public destination contexts**;
- **12–18 secondary settlement / structure / civic / route-stop contexts**;
- **12–20 natural investigation / training / encounter contexts**;
- **8–12 route junction / crossing / pass / border / travel contexts**;
- abundant overlap is allowed;
- secret reservations may reuse plausible generic contexts and should not all be visually distinct.

### Useful natural/man-made vocabulary

Each map should deliberately include a country-appropriate selection of:

- Hidden Village;
- secondary settlements;
- lone compounds / posts / lodges;
- roads and secondary tracks;
- road forks/junctions;
- bridge(s);
- ford(s) / stepping crossings where appropriate;
- river bends / banks;
- lakes/ponds/reservoirs where appropriate;
- coast / harbour / landing point where appropriate;
- border approach / gate / fortress / watch position;
- training clearings / open fields;
- forest clearings;
- canyon/ravine cuts;
- cave/cavern-capable terrain;
- mountain/pass routes;
- cliff shelves/high overlooks;
- waterfalls;
- quarries/mines where country-appropriate;
- farms/terraces/oases where appropriate;
- shrines/temples/ruins where legitimate;
- isolated islands/islets where appropriate;
- old road/abandoned-route affordances;
- generic hidden recesses that can later host secrets.

A map is strongest when these are geographically interconnected rather than scattered like theme-park props.

# 7. WHAT MUST BE VISIBLE VS WHAT MUST STAY HIDDEN

## Must be physically visible

At regional zoom the terrain should visibly support:

- each Great Country's Hidden Village;
- major public settlements/capitals where authored;
- major roads/crossings/pass geography;
- major rivers/lakes/coasts/islands;
- major fortress/harbour/temple-class public structures where that country uses them;
- signature natural geography needed by stable public places.

The precise clickable UI marker remains runtime.

## May be physically subtle

- small villages;
- relay posts;
- tea houses/lodges;
- camps;
- minor estates;
- cemeteries/memorial fields;
- observation posts;
- generic ruins;
- small shrines;
- mines;
- roadside structures.

They need a credible anchor, not an oversized landmark.

## Must remain visually non-disclosing

A concealed reservation with zero-leak authority should receive only plausible host geography.

Do not bake:

- Akatsuki branding;
- Root markings;
- Orochimaru symbolism;
- Uchiha crest;
- White Zetsu forms;
- obvious "secret cave" glow;
- conspicuous unique ruins whose identity is obvious from the art;
- canonical secret labels;
- current event participants/damage/loot.

Runtime may later reveal or accent the exact site when Knowledge permits.

# 8. SPATIAL PRESERVATION DANGER / DO-NOT-BREAK RULES

The redesign becomes dangerous only if it destroys semantic hosting capacity or silently changes identity.

Avoid:

1. replacing Fire's current semantic IDs with new IDs merely because art changed;
2. deleting a required public/optional Fire place because the new composition has nowhere plausible to put it;
3. turning all secrets into visually obvious bespoke landmarks;
4. placing the Hidden Village on a tiny decorative island/ledge with no believable surrounding routes or support territory;
5. generating huge empty scenic zones that cannot host interactions;
6. producing dozens of disconnected decorative islands/rocks with no usable movement/settlement logic;
7. baking current Story/event state into the master;
8. preserving old coordinate ratios at the expense of a better final composition;
9. assuming an old route spline must survive unchanged;
10. making every interesting piece of geography already occupied by a fixed named destination, leaving no neutral territory for future occurrences.

At least **one-third of good hotspot-capable geography should remain semantically neutral at master-generation time** so World can author new Chronicle events later without fighting the art.

# 9. FIRE FINAL-MASTER ACCEPTANCE CHECK

Before UI / Assets declares the new Fire master final, verify visually that it contains credible capacity for:

- 12 Fire public destinations;
- 20 current optional destinations;
- 28 concealed/event reservations **without making them all visible**;
- 12 meaningful travel corridors;
- 14 broad terrain-zone functions;
- at least 40 distinct hotspot-capable contexts overall, 50–60 preferred;
- substantial visible Konoha terrain;
- substantial ordinary-life geography between major landmarks.

This is a **capacity check**, not a requirement to pre-place 72 simultaneous clickable markers.

Once the final Fire binary is committed, World/UI will do one new v3 calibration pass and retire Fire (10) geometry to historical provenance.

# 11. Final World decision

**FIRE:** preserve all current `P/SV/O/S/R/Z` authoring IDs and meanings; regenerate only geography/pixels and later geometry bindings.

**EARTH / WIND / LIGHTNING / WATER:** preserve Hidden Village + any already-consumed durable named identity; old coordinate layouts are not sacred. Generate rich reusable geography first, then World promotes the final country-specific semantic/hosting sets.

**TARGET DENSITY:** minimum ~40 credible hotspot-capable terrain contexts per regional master; 50–60 preferred.

**SECRET RULE:** reserve geography, not disclosure.

**MASTER RULE:** terrain should look like a real country first and a future interactive game surface second — but it must succeed at both.
