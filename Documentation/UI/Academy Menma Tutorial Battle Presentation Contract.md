# Kinjutsu observation

Kinjutsu observation is an independent evidence channel and must never be inferred from `performanceBucket`.

The Kinjutsu dialogue branch requires an authoritative observer-bounded evidence result based on:

actual qualifying Action execution
→ committed occurrence
→ legitimate Anko observer access/perceptibility
→ no applicable observation blocker.

Technique ownership, loadout, access, hover state, selection, or a rejected/uncommitted request never qualify by themselves.

A committed qualifying Action that legitimately misses or fails may still be observed if the execution itself was perceptible and the observer requirements are satisfied.

Canonical rule:

> **performance evidence ≠ Kinjutsu-observation evidence.**
