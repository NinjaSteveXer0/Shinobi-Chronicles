## Purpose

This correction preserves the causal identity of the three Observe escalation choices while making their Battle/resolver consequences materially different in play.

It supersedes only the conflicting Stop-the-Assassin catch-up assumptions in older authority.

## Three distinct Observe escalation routes

### 1. SECURE THE PACKAGE BEFORE THE ASSASSIN

This is the **package-first interception** route.

- Kakashi attempts to reach/extract the package before Masked Interceptor reaches Package Smuggler.
- Interception SUCCESS -> Kakashi secures the package and withdraws.
- Interception FAILURE -> reconverges into the existing **Kakashi Hatake vs Package Smuggler + Masked Interceptor 2-v-1 PL Battle**.

This route's identity is:
> **Beat her to the package.**

### 2. DEFEAT THE ASSASSIN, THEN SECURE THE PACKAGE

This is the **deliberate assassin-first, package-second** route.

- Kakashi fights Masked Interceptor in a **1-v-1 PL Battle**.
- Package Smuggler continues escaping during the Battle.
- Masked Interceptor victory in **1–4 turns** preserves the Package Smuggler catch-up opportunity.
- On the qualifying sequential route, defeating Package Smuggler within **1–3 turns** preserves ANBU Marked Target reach.
- Legitimate downstream ANBU Marked Target reach invokes Pakkun under existing authority.

This route's identity is:
> **Remove her first, then continue the package mission if Kakashi is fast enough.**

### 3. STOP THE ASSASSIN

This remains the **apparent immediate threat priority** route, but Stephen has corrected the older absolute no-catch-up rule.

- Kakashi fights Masked Interceptor in a **1-v-1 PL Battle**.
- Package Smuggler continues escaping with the package while Kakashi fights.
- If Kakashi defeats Masked Interceptor within **1–3 turns**, Package Smuggler remains catchable.
- If Kakashi defeats Masked Interceptor on **turn 4 or later**, Package Smuggler is gone and no pursuit remains.
- A quick Stop-the-Assassin win preserves **Package Smuggler catch-up only**.
- It does **not** create a direct post-MI ANBU Marked Target pursuit option.
- ANBU Marked Target continuation remains a later possibility only through legitimate downstream state after Package Smuggler where separately authorised.

This route's identity is:
> **Stop the apparent killer first; exceptional speed may still save the package pursuit.**

The stricter **1–3** window intentionally makes this route harder than the deliberate **DEFEAT THE ASSASSIN, THEN SECURE THE PACKAGE** route.

## Post-Battle Masked Interceptor decisions

Winning against Masked Interceptor does not automatically terminate her decision space.

Current approved post-Battle action family remains available where the committed state permits:

- **KILL HER** or **ATTEMPT TO KILL HER** according to the lawful lethal semantic;
- **TAKE HER BACK TO ANBU**;
- **TAKE HER TO THE UCHIHA POLICE FORCE**;
- on a qualifying Stop-the-Assassin 1–3-turn win, **GO AFTER PACKAGE SMUGGLER**.

Spending time on a resolver-determined lethal action may still change factual pursuit state according to the owning resolver. Do not invent a second hidden timing penalty for deterministic actions where current authority forbids one.

## Explicit supersession

- there is **no** fast-win catch-up opportunity at all;
