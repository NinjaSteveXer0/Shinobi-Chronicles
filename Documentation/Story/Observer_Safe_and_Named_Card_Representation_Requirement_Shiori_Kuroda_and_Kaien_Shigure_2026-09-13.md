**Date:** 2026-09-13  
**Owner:** Writing — Konoha  
**Status:** **BINDING STORY / REPRESENTATION REQUIREMENT — CHARACTER CREATION / VISUALS CONSUMER; ASSET PRODUCTION SEPARATE**

## 1. Purpose

Stephen identified a representation gap already visible with the Arc-1 `Unknown Man` / Kaien Shigure situation and now relevant again for Shiori Kuroda.

The requirement is:

> **When a persistent person first appears under an observer-safe unknown identity and later has a legitimately revealed personal identity, the observer-safe collectible representation and the named collectible representation may both remain valid representations of the same underlying Character.**

This does **not** create two people.

Preserve:

**stable person != representation**  
**observer-safe label != true identity**  
**identity reveal != card acquisition**  
**named card != retroactive rename of historical unknown card**  
**two representations != two deployable copies of one person**

# 5. System boundaries

Writing closes only the narrative representation requirement.

- **Character Creation / Visuals** owns exact art, card design, portrait fidelity and visual differentiation.
- **PL / Registry / Rank** owns stable persistent identity and representation registration where applicable.
- **Acquisition / Character Systems** owns obtainability, ownership and duplicate semantics.
- **Coding** consumes authoritative representation/identity mappings; it must not infer identity from card title or filename.

Preserve:

- unknown presentation != different person;
- known name != automatic ownership;
- owned observer-safe card != automatic named-card ownership;
- identity reveal != card upgrade/rename;
- collectible representation != Registry person;
- duplicate representation != duplicate participant;
- card availability != deployment legality;
- historical unknown representation remains valid after later Knowledge changes.
