# Shinobi Chronicles — Player-Facing Name Order Convention

**Date:** 2026-09-14  
**Owner:** Writing / Story — Konoha  
**Status:** **BINDING PLAYER-FACING NAMING CONVENTION**

## Core rule

For English player-facing Shinobi Chronicles Story/UI text, use **Western name order: given name first, family name second**.

Therefore:

- **Kakashi Hatake** — correct
- **Hatake Kakashi** — incorrect for ordinary English player-facing presentation

This applies to narration, spoken address where a full name is used, objectives, labels, dialogue subtitles, scene-board text, codex-style player-facing copy, and other ordinary English presentation unless a specific authored cultural/formal exception is deliberately required by the scene.

## Kakashi correction

The Academy Kakashi Origin must use:

> **ANBU OPERATIVE:** “Kakashi Hatake.”

Do not project:

> “Hatake Kakashi.”

The recovered Story authority and future Structured Story Realisation Package should preserve this order consistently.

## Scope boundary

This is a presentation/naming convention. It does not alter identity, Registry keys, internal IDs, sourceOccurrence IDs, character ownership, or other semantic identifiers.

Internal machine-readable identifiers may retain existing technical naming where required by runtime compatibility. The rule governs what the player sees and hears.

## Final lock

> **English player-facing SC naming uses Western order: given name → family name.**
