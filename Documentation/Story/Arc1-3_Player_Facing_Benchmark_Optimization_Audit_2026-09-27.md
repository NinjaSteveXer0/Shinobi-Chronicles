# 7. Universal Arc scene rules

## Scene Board

Each substantial scene should specify:
- exact location/backdrop path where approved;
- exact physically present actors;
- exact observer-facing card/projection;
- when actors enter/leave;
- any concealed identity presentation boundary.

## Segmentation

One Story box = one complete readable dramatic beat.

Avoid:
- scrollable mini-documents;
- one-sentence-per-click fragmentation;
- fake single-option choice prompts.

## Dynamic protagonist rule

If prose depends only on:
- protagonist identity;
- personality;
- relationship;
- earned capability;
- prior Chronicle fact;

the current protagonist's legitimate state must drive the expression.

Do not write a generic protagonist as if every Academy Origin produced Menma.

## NPC autonomy

Current teammates/leaders:
- may advise;
- object;
- abstain;
- participate;
- split;
- intervene;

from their own current Knowledge/history.

Player intent does not command the entire group.

## Battle seam

Writing establishes:
- stakes;
- objective;
- causality;
- participant intent where observable;
- exact Story caller.

Battle establishes:
- actual exchanges;
- withdrawal;
- damage;
- supported control/injury;
- factual result.

Story resumes from the returned facts.
