## Purpose

This closes the distinct causal identity of:

`GET CLOSER -> resolver FAILURE -> STAY ON THE PACKAGE -> pursuit SUCCESS -> TAKE HIM DOWN`

It exists specifically to prevent this choice from becoming a cosmetic reskin of `DEMAND THE PACKAGE`.

The branch difference is binding:

- `DEMAND THE PACKAGE` keeps the package in ANBU Marked Target custody until the ensuing PL Battle is resolved;
- `TAKE HIM DOWN` uses Kakashi's immediate opening intervention to knock the package out of ANBU Marked Target custody **before** the main PL Battle state is established;
- the package therefore becomes a neutral/contested objective on the ground and ANBU Marked Target must win control of it back rather than merely keep possession of it.

This distinction survives into Battle state, defeat consequences, Minato evaluation and the Origin Chronicle Receipt.

---

## 1. Entry state

At branch entry:

- Kakashi has successfully reached ANBU Marked Target after the failed Get Closer branch;
- ANBU Marked Target still possesses the package;
- Pakkun is visibly present under the existing continuity predicate;
- Kakashi and Pakkun have not exchanged names;
- Masked Interceptor remains unseen because no package handoff completed;
- Package Smuggler is no longer the immediate active obstacle;
- the player chooses **TAKE HIM DOWN** rather than `DEMAND THE PACKAGE` or `ASK WHERE THE PACKAGE WAS GOING`.

The semantic intent is immediate physical control of the carrier, not negotiation.

# 2. Player-facing setup

ANBU Marked Target's hand remains over the package.

Kakashi watches it.

Then his attention leaves the package.

Moves to the man's stance instead.

ANBU Marked Target notices.

His hand tightens instinctively over the objective.

Too late.

Kakashi moves.

No demand.

No warning.

He attacks the man's balance first.

ANBU Marked Target twists away and catches the strike on his forearm.

Pakkun reacts at the same moment—not because Kakashi ordered him to.

Because the target's other hand is already moving toward the package.

Pakkun lunges.

The man jerks sideways to avoid him.

The movement saves his leg.

Costs him the package.

It tears loose from beneath his clothing and skids across the wet stone.

All three see it.

The target's expression changes immediately.

So does the fight.

He starts toward it.

Kakashi cuts him off.

Pakkun moves the other way and plants himself between the package and the nearest escape route.

ANBU Marked Target looks from Kakashi—

to Pakkun—

to the package lying several metres away.

**ANBU MARKED TARGET**  
“You've got to be kidding me.”

Pakkun's ears lift.

**PAKKUN**  
“Nope.”

Kakashi settles into position.

For the first time all night, the objective isn't in anyone's hands.

That matters.

The target knows it too.

He stops trying to run.

Now he has to win it back.

# 3. PL Battle caller

**PL BATTLE**

**Kakashi Hatake with Pakkun as a temporary Summon vs ANBU Marked Target**

Pakkun's temporary Battle participation remains Story-authorised only and does not create permanent Summon acquisition, ownership, assignment, roster state or unlock.

No Kakashi/Pakkun name-Knowledge is inferred from Battle participation.

The Battle state is materially different from `DEMAND THE PACKAGE`:

> **The package begins the main Battle state neutral on the ground rather than in ANBU Marked Target custody.**

The encounter is therefore about controlling ANBU Marked Target while denying him recovery of the mission objective.

Do not silently normalise this state back to the Demand branch.

---

# 4. Victory outcome

Battle victory commits:

- Kakashi/Pakkun defeat ANBU Marked Target;
- ANBU Marked Target survives unless another separately authorised action later changes that fact;
- Kakashi secures the neutral package;
- package custody commits to Kakashi;
- Kakashi secures ANBU Marked Target into custody;
- Pakkun remains factually present until explicit authored departure;
- the existing locked four-way post-capture disposition family becomes eligible.

The four existing dispositions remain:

1. Bring him to Uchiha Police Force
2. Let him go
3. Kill him
4. Take him back to the ANBU

Battle victory does not itself select one.

Later debrief/Minato/Receipt expression must preserve that Kakashi chose **immediate physical control** rather than first demanding voluntary surrender.

---

# 5. Defeat outcome — intentionally distinct from Demand the Package

Battle defeat does **not** return the package to ANBU Marked Target by default.

The package had already been separated from him before the main Battle state.

On defeat:

- Kakashi loses the PL Battle;
- ANBU Marked Target remains capable of escape;
- Pakkun remains between the target and the neutral package / mission objective;
- ANBU Marked Target must choose between continuing to contest the objective and using the escape window created by Kakashi's defeat;
- he chooses escape;
- Pakkun does **not** pursue him, because preserving the exposed package is the immediate mission-relevant action available to him;
- ANBU Marked Target escapes without the package;
- Kakashi/Pakkun retain access to and then secure the package after the fight;
- package custody commits to Kakashi;
- ANBU Marked Target is **not** in custody;
- no post-capture disposition menu becomes eligible because there is no captured target;
- Pakkun remains present until explicit authored departure;
- Masked Interceptor remains unseen on this timeline.

Binding defeat state:

> **Kakashi loses the fight but the mission objective is recovered. ANBU Marked Target escapes.**

This is deliberately different from `DEMAND THE PACKAGE` defeat, where ANBU Marked Target escapes **with** the package.

# 6. Branch differentiation lock

`DEMAND THE PACKAGE` and `TAKE HIM DOWN` must never be reduced to alternate dialogue skins over one identical state machine.

### Demand the Package

- objective remains on ANBU Marked Target going into Battle;
- Kakashi first attempts voluntary surrender;
- refusal leads to Battle;
- victory = package + target custody;
- defeat = target escapes with package.

### Take Him Down

- Kakashi skips negotiation and immediately attacks the carrier;
- opening intervention knocks package neutral before the main Battle;
- ANBU Marked Target is now fighting to regain the objective;
- victory = package + target custody;
- defeat = package recovered, target escapes.

The distinction is both tactical and historical.

It must survive:

- Story projection;
- Battle caller state;
- committed outcome;
- later ANBU debrief;
- Minato private evaluation;
- Origin Chronicle Receipt;
- save/load and Chronicle history.

# 7. Final lock

> **TAKE HIM DOWN is not a reskin of DEMAND THE PACKAGE.**
>
> **Kakashi's immediate opening action separates ANBU Marked Target from the package before the PL Battle.**
>
> **Victory -> package recovered + target captured.**
>
> **Defeat -> package still recovered + target escapes.**
>
> **Demand defeat remains target + package escape, preserving materially different risk.**
